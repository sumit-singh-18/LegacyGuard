## Headline: re-order Sprint 7

Reading the code turned up four route-diff defects. Fix them before the route validation run:
1. **Decorator-only edits are invisible.** `symbols.extract` hashes `function_definition`, which leaves out decorators, so adding `@authenticate(...)` produces no target.
2. **Route targets have no line gate.** A route can come out "verified" even when every request stopped at a 401.
3. **Flask `.route(` is not matched.** `checks.ROUTE_DECORATOR` and `indexer/routes.ROUTE_DECORATOR` only match `.get/.post(`.
4. **Renamed or deleted handlers get no route target.**
